# Pinned build-time tooling for building the Android APK in CI
# (GitHub Actions ubuntu-latest). These are the tools that run buildozer /
# python-for-android on the CI runner itself - NOT the app's own runtime
# requirements (those are declared separately in buildozer.spec's
# `requirements = python3,kivy`).
#
# Install with: pip install -r android/requirements-android.txt
#
# This cannot be installed or exercised on Windows (no WSL/Docker/Android
# SDK on this dev machine) - see android/README.md.
#
# IMPORTANT - keep this in sync with buildozer.spec's `p4a.branch`.
# Buildozer and python-for-android are separate projects that must match:
# buildozer clones p4a itself, so an old buildozer paired with p4a master
# silently mixes a years-old driver with a bleeding-edge toolchain. 1.6.0
# and p4a v2026.05.09 were released together (2026-05-12 / 2026-05-09) and
# are the combination pinned here.
buildozer==1.6.0

# Cython is deliberately NOT pinned here: buildozer declares its own
# constraint (1.6.0 requires cython<3.0) and pinning a different range
# just produces an unresolvable conflict. Let buildozer choose.
